# Codex Cheat Sheet

Native SwiftUI macOS app from the OpenAI Codex prompting cheat sheet PDF: browse sections/templates and build prompts with fill-in blanks.

## Run

Requires **Xcode** (SwiftUI macros). Then:

```bash
swift build
swift run
```

Or open `Package.swift` in Xcode and press Cmd+R.

## Where things live

- `Sources/CodexCheatSheet/` — app code (Models + Views)
- `Package.swift` — Swift package config
- `AGENTS.md` — folder rules for this repo
